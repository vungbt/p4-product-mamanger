# ST-20 — Chi phí vận hành

**Trạng thái:** Chưa bắt đầu · **Ưu tiên:** P1 · **Giai đoạn:** Quản lý · **Phạm vi:** API + Web

**Phụ thuộc:** [ST-07](st-07.md)

## Mục tiêu

Ghi các khoản chi (điện nước tổng trả EVN/cấp nước, sửa chữa, internet tổng, thuế, lương dọn dẹp…) để tính lãi/lỗ ở ST-21.

## API

| Method/path (prefix `/api`) | Quyền | Mục đích |
| --- | --- | --- |
| GET/POST /expense-categories, PUT /expense-categories/:id | manage Expense | Danh mục chi (có danh mục mặc định) |
| GET /expenses | read Expense | List chuẩn; lọc toà, kỳ, danh mục, phòng |
| POST /expenses | manage Expense | Thêm khoản chi, kèm ảnh hoá đơn tuỳ chọn |
| PUT /expenses/:id | manage Expense | Sửa (có `version`) |
| DELETE /expenses/:id | manage Expense | Xoá (chi phí không ảnh hưởng hoá đơn người thuê) |

## Màn hình

**Chi phí**: danh sách theo kỳ, tổng theo danh mục ở đầu trang; form thêm nhanh (số tiền, danh mục, ngày, phòng tuỳ chọn, ghi chú, ảnh).

## Điều kiện nghiệm thu

Kỳ của khoản chi suy ra từ ngày chi (giờ Việt Nam); tổng theo danh mục khớp danh sách; ảnh hoá đơn lưu private.
