# ST-21 — Báo cáo và xuất Excel

**Trạng thái:** Chưa bắt đầu · **Ưu tiên:** P1 · **Giai đoạn:** Quản lý · **Phạm vi:** API + Web

**Phụ thuộc:** [ST-19](st-19.md), [ST-20](st-20.md)

## Mục tiêu

Báo cáo theo tháng/năm và xuất Excel để lưu sổ hoặc khai thuế cho thuê nhà.

## API

| Method/path (prefix `/api`) | Quyền | Mục đích |
| --- | --- | --- |
| GET /reports/revenue?buildingId&from&to | read Report | Theo kỳ: phải thu (theo hoá đơn), đã thu (theo ngày thu), chi phí, lãi/lỗ |
| GET /reports/rooms?buildingId&year | read Report | Doanh thu và số tháng có người theo phòng |
| GET /reports/utilities?buildingId&from&to | read Report | Tổng kWh/m³ thu của người thuê so với chi phí điện nước tổng (phát hiện hao hụt) |
| POST /reports/exports | read Report | Tạo file XLSX (hoá đơn, sổ thu, chi phí, công nợ) |

## Màn hình

**Báo cáo**: chọn toà + khoảng thời gian; tab Doanh thu – Chi phí – Lãi/lỗ (biểu đồ cột theo tháng + bảng), tab Theo phòng (tỷ lệ lấp đầy), tab Điện nước (thu so với chi); nút Xuất Excel.

## Quy tắc

"Đã thu" tính theo ngày thu thực tế, "phải thu" theo kỳ hoá đơn; ghi rõ trên giao diện để không nhầm. Thanh toán bị huỷ không tính.

## Điều kiện nghiệm thu

Số liệu báo cáo khớp với sổ thu/chi phí/hoá đơn của cùng khoảng (integration); file Excel mở được, định dạng tiền đúng, tên sheet tiếng Việt.
