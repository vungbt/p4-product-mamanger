# ST-05 — CI, test integration và dữ liệu seed

**Trạng thái:** Chưa bắt đầu · **Ưu tiên:** P0 · **Giai đoạn:** Nền tảng · **Phạm vi:** CI, `apps/stay/api/tests`, seeders

**Phụ thuộc:** [ST-03](st-03.md), [ST-04](st-04.md)

## Mục tiêu

Mọi task nghiệp vụ sau đều có test chạy trên CI ngay từ đầu, kèm dữ liệu dev đủ để thao tác.

## Phạm vi

- Job CI `stay` (GitHub + GitLab): lint, typecheck, unit test, build web, OpenAPI/SDK check.
- Job `stay-integration`: Postgres service, migrate, seed, chạy stay-api, toàn bộ test integration; **fail nếu có suite bị skip** (giống `scripts/test-api-integration.sh`).
- Seed dev (idempotent, chỉ local/CI): 1 toà (`A`, 3 tầng, 12 phòng), bảng giá mặc định, ~15 người thuê, 9 hợp đồng đang hiệu lực, chỉ số 3 kỳ gần nhất, vài hoá đơn đã thu/chưa thu/quá hạn.
- Helper test: tạo owner, đăng nhập, gọi API có kiểu qua SDK; dọn dữ liệu sau test không để rác.
- Unit test riêng cho thư viện tính tiền ([rules.md](rules.md)) chạy không cần DB.

## Điều kiện nghiệm thu

1. CI xanh trên PR; cố ý tắt API thì job integration fail (không skip âm thầm).
2. Chạy seed hai lần không nhân đôi dữ liệu.
3. Hướng dẫn chạy local trong README của `apps/stay/api`.
