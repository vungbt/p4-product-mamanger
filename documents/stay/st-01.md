# ST-01 — Tách lõi server dùng chung

**Trạng thái:** Chưa bắt đầu · **Ưu tiên:** P0 · **Giai đoạn:** Nền tảng · **Phạm vi:** `libs/server-core`, `apps/api`

**Phụ thuộc:** Không có

## Mục tiêu

Đưa các phần hạ tầng server đang nằm trong `apps/api/src` của P4 ra `libs/server-core` để `apps/stay-api` dùng lại. **P4 không đổi hành vi**; đây là refactor có test bảo vệ.

## Phạm vi

| Phần | Nguồn hiện tại (P4) | Ghi chú |
| --- | --- | --- |
| Better Auth factory | `apps/api/src/configs/better-auth.ts` | Nhận `appName`, `cookiePrefix`, pool, hook audit, `trustedOrigins`, chặn mật khẩu công khai làm tham số |
| Audit | `apps/api/src/shared/audit/*` | `auditedCommand`, `auditedTransaction`, `applyAuditPolicies`, redact |
| List query | `apps/api/src/shared/list-query.ts`, `list-filters.ts`, `list-search.ts` | Chuẩn `page/pageSize/q/sortBy/sortOrder` |
| DTO | `apps/api/src/utils/select-fields.ts`, `types/database.ts` | `selectFields`, `ModelOrder`, `StringField` |
| Lỗi và response | `utils/errors`, `res.jsonApi`, `apiHandler`, `http-input` | Envelope `{ data, meta }`, lỗi field |
| Middleware | `ability.middleware.ts`, `rate-limit.middleware.ts`, `auth.middleware.ts`, `cookie-origin.ts` | Ability nhận factory theo app (ST-02) |
| Cấu hình production | `configs/production.ts` | `assertSecret`, kiểm tra HTTPS/CORS |
| Idempotency, outbox | `shared/commerce/persistence.ts` | Chỉ phần chung (`runIdempotent`, `enqueueEvent`) |

Các phần phụ thuộc model Sequelize nhận model/`sequelize` qua tham số hoặc factory, không import model của P4. Package export như `@p4/ability` (build ra `dist`, có `./shared`).

## Điều kiện nghiệm thu

1. `apps/api` import từ `@p4/server-core`; không còn bản sao code trong `apps/api/src`.
2. `pnpm --filter @p4/api typecheck`, `test:lists`, `scripts/test-api-integration.sh` (99 test) và OpenAPI check đều xanh, **không phải sửa test** để pass.
3. `openapi.yaml` sinh lại không đổi.
4. Image Docker của P4 build và chạy được (copy thêm `libs/server-core`).
5. README của `libs/server-core` mô tả từng module và cách cấu hình cho app mới.

## Ngoài phạm vi

Không đổi API contract P4, không gộp DB, không chuyển module nghiệp vụ (catalog, orders…).
