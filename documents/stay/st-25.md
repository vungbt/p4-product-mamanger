# ST-25 — Cổng người thuê

**Trạng thái:** Chưa bắt đầu · **Ưu tiên:** P2 · **Giai đoạn:** Mở rộng · **Phạm vi:** API + Web

**Phụ thuộc:** [ST-16](st-16.md), [ST-22](st-22.md)

## Mục tiêu

Người thuê tự xem hoá đơn, lịch sử thanh toán và báo hỏng, **không cần tạo tài khoản**: đăng nhập bằng link riêng của hợp đồng (magic link qua SĐT/email, hoặc link cố định có thể thu hồi).

## API

| Method/path (prefix `/api`) | Quyền | Mục đích |
| --- | --- | --- |
| POST /contracts/:id/portal-link | manage Contract | Tạo/thu hồi link cổng của hợp đồng |
| GET /portal/:token | Công khai (token) | Hợp đồng tóm tắt, hoá đơn, công nợ, thông tin chuyển khoản |
| POST /portal/:token/maintenance | Công khai (token) | Báo hỏng kèm ảnh (giới hạn tần suất) |

## Màn hình

**Cổng người thuê** (giao diện tối giản, mobile): hoá đơn kỳ hiện tại kèm VietQR, các kỳ trước, báo hỏng, số điện thoại chủ trọ.

## Quy tắc

Token chỉ lưu hash, thu hồi khi hợp đồng kết thúc; rate limit các endpoint công khai; người thuê chỉ thấy dữ liệu hợp đồng của mình (rule CASL `tenant` có điều kiện `contractId`).

## Điều kiện nghiệm thu

Token hợp đồng A không đọc được dữ liệu hợp đồng B; hợp đồng kết thúc thì link chết; báo hỏng tạo việc ở ST-22.
