# ST-09 — Người thuê và import

**Trạng thái:** Chưa bắt đầu · **Ưu tiên:** P0 · **Giai đoạn:** Dữ liệu nền · **Phạm vi:** API + Web

**Phụ thuộc:** [ST-07](st-07.md)

## Mục tiêu

Lưu hồ sơ người thuê (dùng cho hợp đồng, liên hệ và khai báo tạm trú), kèm import từ file khi chuyển dữ liệu cũ sang.

## API

| Method/path (prefix `/api`) | Quyền | Mục đích |
| --- | --- | --- |
| GET /tenants | read Tenant | List chuẩn; tìm theo tên/SĐT/CCCD; lọc đang ở/đã rời/toà |
| POST /tenants | manage Tenant | Tạo |
| GET /tenants/:id | read Tenant | Hồ sơ, xe, giấy tờ, lịch sử hợp đồng |
| PUT /tenants/:id | manage Tenant | Sửa (có `version`) |
| POST /tenants/:id/documents | manage Tenant | Gắn ảnh CCCD đã upload (upload ticket private như P4) |
| POST/PUT/DELETE /tenants/:id/vehicles[/:vehicleId] | manage Tenant | Quản lý xe |
| POST /tenants/import/preview | manage Tenant | Kiểm tra file CSV/XLSX, trả lỗi **từng dòng**, không ghi DB |
| POST /tenants/import | manage Tenant | Ghi các dòng hợp lệ của bản preview đã duyệt, có `Idempotency-Key` |
| POST /tenants/:id/archive | manage Tenant | Lưu trữ (khi không còn ở hợp đồng hiệu lực) |

## Dữ liệu

`tenants`, `tenant_documents`, `vehicles`. CCCD unique khi có; SĐT chuẩn hoá dạng `0xxxxxxxxx`.

## Màn hình

- **Danh sách người thuê**: tên, SĐT (bấm để gọi/Zalo trên mobile), phòng hiện tại, trạng thái.
- **Hồ sơ người thuê**: thông tin cá nhân, ảnh CCCD (xem ảnh private qua URL ký ngắn hạn), xe, các hợp đồng đã/đang ở.
- **Form người thuê**: nhập nhanh tên + SĐT là đủ để lưu; các trường khác bổ sung sau.
- **Quét CCCD** (form người thuê và "Tạo nhanh người thuê" trong wizard hợp đồng): mở camera sau (getUserMedia) hoặc chọn ảnh thẻ, đọc mã QR ngay trên trình duyệt (`BarcodeDetector` có sẵn, nếu không thì `jsqr` tải lười) rồi điền họ tên, số CCCD, ngày sinh, giới tính, địa chỉ thường trú, ngày cấp; báo các trường đã điền, chủ trọ kiểm tra rồi mới lưu. Nội dung QR (`số CCCD|số CMND cũ|họ tên|ngày sinh DDMMYYYY|giới tính|thường trú|ngày cấp DDMMYYYY`, có thể thiếu CMND cũ hoặc chỉ 6 trường) phân tích bằng `parseCccdQr` của `@stay/shared`. Không gửi/ghi log nội dung QR, không dùng API bên thứ ba. Từ chối quyền camera / không có camera / mã không đọc được → thông báo tiếng Việt, chọn ảnh hoặc nhập tay.
- **Import**: tải file mẫu → chọn file → bảng xem trước (dòng lỗi tô đỏ, lý do theo cột) → xác nhận nhập các dòng hợp lệ.

## Quy tắc

- Không bao giờ tự gán phòng hay tự điền dữ liệu giả (lỗi của SCM). Import chỉ tạo hồ sơ; gắn vào phòng làm ở hợp đồng.
- Dữ liệu cá nhân không xuất hiện trong log/audit dạng rõ (redact CCCD, ảnh).

## Điều kiện nghiệm thu

CCCD trùng → lỗi field kèm liên kết tới hồ sơ đã có; import file 200 dòng có lỗi rải rác → báo đúng dòng/cột, gọi lại import không tạo trùng; ảnh CCCD không truy cập được bằng URL công khai.
