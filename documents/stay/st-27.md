# ST-27 — Người quản lý theo toà

**Trạng thái:** Đã triển khai; chờ kiểm thử DB/E2E · **Ưu tiên:** P2 · **Giai đoạn:** Mở rộng · **Phạm vi:** API + Web

**Phụ thuộc:** [ST-02](st-02.md), [ST-19](st-19.md)

## Mục tiêu

Cho phép thêm người quản lý chỉ thao tác trên một số toà, với quyền giới hạn (ví dụ được chốt số, thu tiền; không được sửa đơn giá hay void hoá đơn).

## API

| Method/path (prefix `/api`) | Quyền | Mục đích |
| --- | --- | --- |
| GET /members, POST /members/invitations | manage Member | Danh sách, mời người quản lý (email) |
| PUT /members/:id | manage Member | Gán toà và nhóm quyền |
| POST /members/:id/disable | manage Member | Khoá tài khoản, thu hồi phiên |

## Màn hình

**Thành viên**: danh sách người quản lý (email, toà được gán, nhóm quyền, trạng thái); mời qua email; sửa toà/quyền; khoá tài khoản.

## Thay đổi kỹ thuật

- Rule CASL `manager` có điều kiện `{ buildingId: { $in: [...] } }`.
- **`accessibleWhere`**: chuyển rule CASL thành `where` của Sequelize (dùng `rulesToCondition` của `@casl/ability/extra`), áp dụng cho mọi list API và tra cứu theo id. Bộ chuyển chỉ hỗ trợ các toán tử đang dùng (`$eq`, `$in`), gặp toán tử lạ thì báo lỗi thay vì bỏ qua.
- Bộ chọn toà chỉ hiện toà được gán.

## Điều kiện nghiệm thu

Manager toà A không đọc/ghi được bất kỳ dữ liệu toà B qua list, id trực tiếp, báo cáo hay xuất Excel (test cho từng resource); đổi quyền giữa phiên có hiệu lực ngay ở lần gọi kế tiếp.

## Kết quả thực hiện

- API danh sách/mời/sửa/khoá, audit và optimistic locking; migration `20261206000100-member-permissions.cjs` có down.
- CASL nhóm quyền + bộ chuyển `accessibleWhere` (`rulesToCondition`); scope query trực tiếp, báo cáo/xuất theo toà, các quan hệ kế thừa scope từ bản ghi cha.
- O-33 dùng FilterBar/ListTable, nhiều toà, nhóm quyền, xác nhận khoá; trang đặt mật khẩu lời mời.
- OpenAPI → SDK và hooks cho thành viên. Integration tests kiểm tra cách ly, sửa quyền trong cùng phiên, thu hồi phiên; unit tests bộ chuyển SQL và CASL.
- Hạn chế vận hành: dùng auth email hiện có (local ghi link; production chưa có transport). Outbox invitation chạy trong worker và thử lại lỗi giao thư.
- Môi trường sandbox chặn kết nối localhost/Docker (`EPERM`); chưa áp dụng migration hoặc chạy integration/E2E thực tế.
