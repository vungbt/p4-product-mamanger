# FE-26 — CMS bài viết, trang và taxonomy

Trạng thái: **Chưa bắt đầu** · Portal: **Admin**

## Mục tiêu

Hoàn thiện luồng cms bài viết, trang và taxonomy với API local đã triển khai. Đây là task frontend độc lập; tạo file task không có nghĩa màn hình đã hoàn thành.

## Phụ thuộc

[FE-04](fe-04.md), [FE-38](fe-38.md)

## API và contract

Scalar local: `http://127.0.0.1:3001/api/docs`. Chọn Node.js → Axios để tham khảo; FE dùng service và API client hiện có. Đối chiếu schema hiện hành trước khi triển khai.

- `GET /api/admin/posts`
- `POST /api/admin/posts`
- `GET /api/admin/posts/{id}`
- `PATCH /api/admin/posts/{id}`
- `POST /api/admin/posts/{id}/publish`
- `POST /api/admin/posts/{id}/archive`
- `GET /api/admin/posts/{id}/revisions`
- `GET /api/admin/pages`
- `POST /api/admin/pages`
- `GET /api/admin/pages/{id}`
- `PATCH /api/admin/pages/{id}`
- `POST /api/admin/pages/{id}/publish`
- `POST /api/admin/pages/{id}/archive`
- `GET /api/admin/pages/{id}/revisions`
- `GET /api/post-categories`
- `POST /api/admin/post-categories`
- `PATCH /api/admin/post-categories/{id}`
- `GET /api/post-tags`
- `POST /api/admin/post-tags`
- `PATCH /api/admin/post-tags/{id}`

Types lấy từ `@p4/shared`, `@p4/processes/shared`, `@p4/realtime/shared`; không tự định nghĩa lại enum/state phía FE.

## Phạm vi và điều kiện nghiệm thu

1. Draft/publish/archive/schedule, category/tag, revisions và SEO; không render HTML tuỳ ý.
2. Sửa draft không thay public snapshot; ảnh qua ticket và liên kết HTTPS hợp lệ.
3. Ảnh bìa và ảnh trong nội dung dùng upload chung ở FE-38.
4. Xem được revision; lên lịch gửi `scheduledAt` theo UTC và hiển thị theo giờ địa phương.

## Cách tổ chức và kiểm chứng

- HTTP service trong `apps/web/src/services`; state/query/mutation/handler trong hook feature; component trình bày cùng feature, props dùng ở đâu định nghĩa ở đó.
- Dùng component/icon/token của `@itclabs/react-ui`, tái sử dụng `libs/blocks`; không dựng lại UI primitives hoặc thêm wrapper/view chỉ để chuyển props.
- Áp dụng [quy ước UI và API](README.md#quy-ước-nghiệm-thu-chung), có loading/empty/error/retry; lỗi field vào field, lỗi chung hiển thị tại form.
- Chạy typecheck/lint/build phù hợp và thao tác luồng thật qua API local. Ghi endpoint, tình huống, kết quả trong phần dưới; không coi mock data là nghiệm thu API.
