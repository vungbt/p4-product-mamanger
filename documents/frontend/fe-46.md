# FE-46 — Bảo mật tài khoản và quản lý phiên

Trạng thái: **Chưa bắt đầu** · Portal: **Chung**

## Mục tiêu

Hoàn thiện bảo mật tài khoản và quản lý phiên theo contract API hiện hành. Task chỉ hoàn thành khi màn/luồng đã tích hợp API thật và có kết quả nghiệm thu, không chỉ khi API/SDK đã tồn tại.

## Phụ thuộc

[FE-01](fe-01.md), [FE-09](fe-09.md)

## API và contract

Đối chiếu Scalar và generated contract hiện hành trước khi làm; chỉ dùng các field/query/action được API hỗ trợ.

- `POST /api/auth/change-password`
- `POST /api/auth/verify-password`
- `GET /api/auth/list-sessions`
- `POST /api/auth/revoke-session`
- `POST /api/auth/revoke-sessions`
- `POST /api/auth/revoke-other-sessions`
- `PATCH /api/auth/password`
- `GET /api/me/sessions`
- `DELETE /api/me/sessions/{id}`
- `POST /api/me/sessions/revoke-others`

## Phạm vi và điều kiện nghiệm thu

1. Màn security dùng cho Admin và Storefront: thay mật khẩu, xem phiên hiện tại/thiết bị và thu hồi một/tất cả phiên khác.
2. Chọn một luồng native hoặc compatibility cho mỗi form; không gọi hai engine hoặc ghi token vào localStorage. Tôn trọng việc đổi mật khẩu có thể revoke phiên.
3. Revoke phiên đang dùng dọn cache/socket rồi login; revoke phiên khác giữ phiên hiện tại. Hiển thị thời gian/expiry theo locale, che token khỏi UI/log.

## Cách tổ chức và kiểm chứng

- Request, query keys và query/mutation hooks thuộc `@p4/api-sdk`; mở rộng resource hooks tại SDK nếu thiếu. Component gọi trực tiếp; hook cạnh page chỉ giữ state/handler của màn, không tạo hook chuyển tiếp.
- Dùng `@itclabs/react-ui`, icon/theme P4 và business blocks sẵn có; áp dụng [quy ước chung](README.md#quy-ước-nghiệm-thu-chung).
- Kiểm chứng API thật local: happy path, lỗi field, 401/403/404/409, pending/empty, retry và dữ liệu stale; desktop/mobile, keyboard và VI/EN. Không dùng production để tạo dữ liệu test.
- Chạy SDK typecheck/test khi đổi hooks, web build và root lint; ghi kết quả trước khi cập nhật trạng thái.

## Kết quả thực hiện

Chưa thực hiện. Ghi màn/route, API/hook đã ghép, bằng chứng kiểm chứng và giới hạn còn lại; đồng bộ trạng thái ở mục lục.
