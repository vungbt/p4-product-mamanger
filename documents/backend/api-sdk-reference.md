# API và SDK theo platform

Tự sinh từ OpenAPI; không sửa tay. Platform là nhóm sử dụng, không thay thế permission/ownership.

Hooks: `@p4/api-sdk/react`. Helpers và input: `@p4/api-sdk/shared`. Mọi helper nhận SDK trước input; hooks GET nhận input/settings, hooks mutation trả `mutate`/`mutateAsync`.
