# FE-04 — Form sản phẩm và gallery nhiều ảnh

Trạng thái: **Đã triển khai · Chờ nghiệm thu API** · Portal: **Admin**

## Mục tiêu

Hoàn thiện form sản phẩm và gallery nhiều ảnh theo contract API hiện hành. Task chỉ hoàn thành khi màn/luồng đã tích hợp API thật và có kết quả nghiệm thu, không chỉ khi API/SDK đã tồn tại.

## Phụ thuộc

[FE-03](fe-03.md), [FE-38](fe-38.md), [FE-41](fe-41.md)

## API và contract

Scalar local: `http://127.0.0.1:3001/api/docs`. Chọn Node.js → Axios để tham khảo; FE dùng `@p4/api-sdk` và hooks resource. Đối chiếu schema hiện hành trước khi triển khai.

- `POST /api/products`
- `PUT /api/products/{id}`
- `DELETE /api/products/{id}`
- `POST /api/products/{id}/images`
- `DELETE /api/products/{id}/images/{imageId}`
- `PATCH /api/products/{id}/publication`
- `GET /api/admin/size-guides`

Types request/response lấy từ contract sinh trong `@p4/api-sdk/shared`; enum/state nghiệp vụ dùng `@p4/shared`, `@p4/processes/shared`, `@p4/realtime/shared`. Không định nghĩa trùng hoặc ép type để lách schema.

## Phạm vi và điều kiện nghiệm thu

1. Tạo/sửa tên, slug, mô tả, category, SEO, size guide; publish chỉ sau khi API cho phép.
2. Upload nhiều ảnh qua ticket/batch process; hiển thị từng ảnh thành công/lỗi; không gắn file chưa verify.
3. Dùng upload chung ở FE-38, không tự viết luồng upload riêng.
4. Lỗi validate hiển thị đúng field; rời form khi còn thay đổi chưa lưu có cảnh báo.
5. Xoá sản phẩm có xác nhận và hiển thị lỗi khi API từ chối.

## Cách tổ chức và kiểm chứng

- API client, query keys và resource query/mutation hooks nằm trong `libs/api-sdk`; component gọi hook trực tiếp. Hook feature chỉ xử lý state/handler màn hình, không tạo service hoặc hook chuyển tiếp. Props dùng ở đâu định nghĩa ở đó.
- Dùng component/icon/token của `@itclabs/react-ui`, tái sử dụng `libs/blocks`; không dựng lại UI primitives hoặc thêm wrapper/view chỉ để chuyển props.
- Áp dụng [quy ước UI và API](README.md#quy-ước-nghiệm-thu-chung), có loading/empty/error/retry; lỗi field vào field, lỗi chung hiển thị tại form.
- Chạy typecheck/lint/build phù hợp và thao tác luồng thật qua API local. Ghi endpoint, tình huống, kết quả trong phần dưới; không coi mock data là nghiệm thu API.

## Kết quả thực hiện

Đã triển khai form tạo nháp/chỉnh sửa, mô tả HTML qua editor của kit, category/size guide từ API, SEO và gallery nhiều ảnh. Upload dùng hook chung FE-38 (ticket → provider → complete), có tiến độ/lỗi từng file và retry giữ ticket. Update gửi expectedVersion, lỗi field hiển thị tại trường, 409 có tải lại; rời trang có cảnh báo; xóa có xác nhận và giữ thông báo từ chối của API.

Build web và lint qua; 9/9 kiểm thử upload/điều hướng qua. Chưa hoàn tất nghiệm thu API/browser: API local không chạy, sandbox chặn Docker socket, Vite port binding và Chromium launch. Không tạo container mới. Xem [ánh xạ ca nghiệm thu và bằng chứng](../../../specs/018-fe-04/checklists/acceptance.md).

Giới hạn: SDK request chưa nhận null cho categoryId/sizeGuideId, nên chỉ chọn/đổi tham chiếu; chưa xóa tham chiếu đã lưu. Publish thuộc FE-03; các màn upload cũ ngoài phạm vi FE-04 không thay đổi. Không sửa backend, package.json hoặc lockfile.
