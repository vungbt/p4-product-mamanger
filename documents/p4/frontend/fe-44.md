# FE-44 — Chi tiết sản phẩm, gallery và chọn SKU

Trạng thái: **Chưa bắt đầu** · Portal: **Storefront**

## Mục tiêu

Hoàn thiện chi tiết sản phẩm, gallery và chọn sku theo contract API hiện hành. Task chỉ hoàn thành khi màn/luồng đã tích hợp API thật và có kết quả nghiệm thu, không chỉ khi API/SDK đã tồn tại.

## Phụ thuộc

[FE-07](fe-07.md), [FE-43](fe-43.md), [FE-41](fe-41.md)

## API và contract

Đối chiếu Scalar và generated contract hiện hành trước khi làm; chỉ dùng các field/query/action được API hỗ trợ.

- `GET /api/products/by-slug/{slug}`
- `GET /api/products/{id}`
- `GET /api/products/{id}/variants`
- `GET /api/products/{id}/reviews`
- `GET /api/products/{id}/review-summary`

## Phạm vi và điều kiện nghiệm thu

1. Route theo slug; gallery, giá, mô tả, size guide và review summary lấy dữ liệu thật, có 404 và chuyển slug cũ đúng contract.
2. Chọn size/màu xác định đúng SKU, đổi ảnh/giá/available; tổ hợp không hợp lệ hoặc hết hàng không thêm giỏ.
3. Số lượng không vượt available, thêm giỏ chuyển đúng variant ID; keyboard/mobile hoạt động và không dùng productId thay SKU.

## Cách tổ chức và kiểm chứng

- Request, query keys và query/mutation hooks thuộc `@p4/api-sdk`; mở rộng resource hooks tại SDK nếu thiếu. Component gọi trực tiếp; hook cạnh page chỉ giữ state/handler của màn, không tạo hook chuyển tiếp.
- Dùng `@itclabs/react-ui`, icon/theme P4 và business blocks sẵn có; áp dụng [quy ước chung](README.md#quy-ước-nghiệm-thu-chung).
- Kiểm chứng API thật local: happy path, lỗi field, 401/403/404/409, pending/empty, retry và dữ liệu stale; desktop/mobile, keyboard và VI/EN. Không dùng production để tạo dữ liệu test.
- Chạy SDK typecheck/test khi đổi hooks, web build và root lint; ghi kết quả trước khi cập nhật trạng thái.

## Kết quả thực hiện

Chưa thực hiện. Ghi màn/route, API/hook đã ghép, bằng chứng kiểm chứng và giới hạn còn lại; đồng bộ trạng thái ở mục lục.
